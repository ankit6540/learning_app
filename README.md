# 📚 Learning App – Online Learning Platform

Learning App is a Flutter-based educational mobile application designed to help users learn programming and technology through structured courses, video lessons, notes, and an easy-to-use interface.

### ✨ Features

* 📚 Explore different programming courses
* 💻 Flutter, Python and other technology courses
* 🎥 Video-based lessons
* 📝 Course notes and learning materials
* ▶️ Start Learning functionality
* 📋 Lesson-wise course structure
* 👤 User profile section
* 🔍 Simple and user-friendly navigation
* 📱 Responsive Flutter UI

### 🛠️ Technologies Used

* Flutter
* Dart
* Firebase
* Android Studio
* Git & GitHub

### 🎯 Purpose

The goal of Learning App is to provide beginners with a simple platform where they can learn programming concepts through courses, videos, and notes in an organized way.

**Built with Flutter 💙**
